## TL;DR
Positioning não é um slogan: é definir o contexto (categoria de mercado) em que seu produto é claramente líder em entregar algo que um conjunto bem-definido de clientes valoriza muito. Dunford parte SEMPRE das alternativas competitivas reais (o que o cliente faria se você não existisse), extrai os atributos únicos, traduz em valor, segmenta quem mais liga para esse valor e só então escolhe a categoria. Para produtos de IA, a First Round reforça: "AI-powered" deixou de ser posição — diferenciação tem que ser legível, opinativa e revisada a cada poucos meses.

## Pontos-chave
- Definição: "Positioning defines how your product is a leader at delivering something that a well-defined set of customers cares a lot about."
- Cinco componentes em ordem (não é fill-in-the-blanks, é workflow sequencial):
  1. Alternativas competitivas — o que o cliente faria se você não existisse (não rivais teóricos).
  2. Atributos únicos — features/capacidades que as alternativas não têm.
  3. Valor — o benefício que esses atributos destravam para o comprador.
  4. Segmentação do cliente-alvo — quem liga MAIS para esse valor diferenciado.
  5. Categoria de mercado — o contexto que torna o valor óbvio para o alvo.
- Começar pelas alternativas é o teste de diferenciação: "the starting point had to be competitive alternatives. If it wasn't...it wasn't differentiated."
- Maioria dos startups deve posicionar dentro de categoria existente, não inventar categoria nova.
- Para IA (First Round / Arielle Jackson): "AI-powered X" perde sentido assim que há vários concorrentes credíveis; diferenças invisíveis = produtos percebidos como intercambiáveis → comprador escolhe o mais seguro/fácil de justificar.
- Receita para IA: (1) POV opinativo — "what you believe that everyone else doesn't"; (2) posicionamento vivo, revisitado a cada poucos meses; (3) distinção visual/verbal tão própria que copiá-la pareceria ridículo.

## Frameworks / números
- Framework central: 5 componentes de posicionamento (alternativas → atributos → valor → segmento → categoria). Livro "Obviously Awesome" detalha como método de 10 passos.
- Benchmark de categoria: ~90% das techs que abriram capital nos últimos 5 anos posicionaram-se em mercados existentes (não criaram categoria).
- Para IA: posicionamento como "living thing" revisado a cada poucos meses (vs. doc estático anual).

## Aplicação ao Pilar
- Definir a alternativa competitiva REAL do orçamento de honorários: hoje é planilha Excel + chute do sócio, não "outro SaaS". O agente de orçamento compete com a planilha — toda mensagem de valor deve atacar isso (erro de margem, retrabalho, precificar no escuro).
- Não vender "Pilar com IA" (anti-posição segundo a First Round). Vender a categoria/valor: "saiba se cada projeto dá lucro antes de terminar" + "o agente monta o orçamento horas×custo×margem com você no controle (HITL)". Atributo único legível = vertical AEC + cálculo de honorários, não "tem IA".
- Escolher categoria explícita: posicionar dentro de uma categoria que o sócio de engenharia já entende (ex.: "gestão financeira/orçamento para escritórios de engenharia"), não inventar categoria nova — coerente com o benchmark dos 90%.
- Segmentar pelo cliente que MAIS liga para margem-por-projeto (escritórios multidisciplinares que vendem horas) e tratar posicionamento como documento vivo, revisado a cada ciclo conforme Vobi e concorrentes IA evoluem.
