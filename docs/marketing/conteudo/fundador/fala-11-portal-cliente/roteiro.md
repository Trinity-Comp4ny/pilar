# O cliente que liga toda semana

**Formato:** Reel 9:16 do fundador, gravado no celular · **Status:** a gravar


## Roteiro (uma fala por respiração, olhando para a lente)

1. Todo escritório tem aquele cliente que liga toda semana para saber como está.
2. E alguém para o que está fazendo para montar a resposta.
3. Na Pilar, o cliente acompanha pelo portal, com um link.
4. Ele vê só o que você liberar.
5. O cliente fica mais tranquilo, e o seu dia volta a ser seu.

## Como gravar e finalizar

1. Grave na vertical (câmera traseira, luz de janela, microfone de lapela). Teleprompter: `docs/marketing/gravacao/teleprompter.html`.
2. Salve como `docs/marketing/video-v2/footage/fala-11-portal-cliente.mp4`.
3. Rode `./make.sh fala-11-portal-cliente dark` em `docs/marketing/video-v2/`. A legenda palavra a palavra, as telas e a trilha entram sozinhas.
4. Rode `python3 docs/marketing/conteudo/organizar.py` para trazer o vídeo para esta pasta.
