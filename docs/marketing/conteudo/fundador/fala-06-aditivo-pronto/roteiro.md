# O aditivo que chega pronto

**Formato:** Reel 9:16 do fundador, gravado no celular · **Status:** a gravar


## Roteiro (uma fala por respiração, olhando para a lente)

1. Pedir aditivo é a parte mais chata do projeto. Ninguém gosta.
2. Na Pilar, quando o projeto passa do orçamento de horas, o aditivo já chega montado.
3. Ele cita as despesas e os apontamentos que sustentam cada valor.
4. Você revisa, aprova e manda para o cliente com a base na mão.
5. Aditivo com base não parece cobrança. Parece profissionalismo.

## Como gravar e finalizar

1. Grave na vertical (câmera traseira, luz de janela, microfone de lapela). Teleprompter: `docs/marketing/gravacao/teleprompter.html`.
2. Salve como `docs/marketing/video-v2/footage/fala-06-aditivo-pronto.mp4`.
3. Rode `./make.sh fala-06-aditivo-pronto dark` em `docs/marketing/video-v2/`. A legenda palavra a palavra, as telas e a trilha entram sozinhas.
4. Rode `python3 docs/marketing/conteudo/organizar.py` para trazer o vídeo para esta pasta.
