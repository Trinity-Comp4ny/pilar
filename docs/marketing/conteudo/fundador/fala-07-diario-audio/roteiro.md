# Diário de obra falado

**Formato:** Reel 9:16 do fundador, gravado no celular · **Status:** a gravar


## Roteiro (uma fala por respiração, olhando para a lente)

1. O mestre de obras não vai digitar relatório. E tudo bem.
2. Ele grava um áudio contando o dia, e a Pilar organiza o registro.
3. O que avançou, o que ficou pendente, quantas pessoas, o clima.
4. O registro nasce interno e só vai para o cliente quando você liberar.
5. Menos grupo de WhatsApp, mais obra documentada.

## Como gravar e finalizar

1. Grave na vertical (câmera traseira, luz de janela, microfone de lapela). Teleprompter: `docs/marketing/gravacao/teleprompter.html`.
2. Salve como `docs/marketing/video-v2/footage/fala-07-diario-audio.mp4`.
3. Rode `./make.sh fala-07-diario-audio dark` em `docs/marketing/video-v2/`. A legenda palavra a palavra, as telas e a trilha entram sozinhas.
4. Rode `python3 docs/marketing/conteudo/organizar.py` para trazer o vídeo para esta pasta.
