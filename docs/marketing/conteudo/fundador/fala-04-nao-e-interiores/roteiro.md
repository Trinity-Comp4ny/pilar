# Engenharia não é interiores

**Formato:** Reel 9:16 do fundador, gravado no celular · **Status:** a gravar


## Roteiro (uma fala por respiração, olhando para a lente)

1. Quase todo conteúdo de gestão de escritório no Instagram é de arquitetura de interiores.
2. Mas quem faz estrutural, elétrico e hidrossanitário vende por disciplina, mede hora e acompanha a obra.
3. É um negócio diferente, com problemas diferentes.
4. A Pilar foi feita para esse escritório: disciplina, prazo, responsável e lucro de cada projeto.
5. Se você é desse mundo, me segue que o conteúdo é para você.

## Como gravar e finalizar

1. Grave na vertical (câmera traseira, luz de janela, microfone de lapela). Teleprompter: `docs/marketing/gravacao/teleprompter.html`.
2. Salve como `docs/marketing/video-v2/footage/fala-04-nao-e-interiores.mp4`.
3. Rode `./make.sh fala-04-nao-e-interiores dark` em `docs/marketing/video-v2/`. A legenda palavra a palavra, as telas e a trilha entram sozinhas.
4. Rode `python3 docs/marketing/conteudo/organizar.py` para trazer o vídeo para esta pasta.
