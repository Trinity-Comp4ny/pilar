# O dia em que a margem apareceu no fim

**Formato:** Reel 9:16 do fundador, gravado no celular · **Status:** a gravar


## Roteiro (uma fala por respiração, olhando para a lente)

1. Imagina um projeto que parecia ótimo: contrato bom, cliente bom.
2. Aí veio uma revisão sem aditivo, uma compatibilização refeita, uma versão errada.
3. No fim, o lucro caiu de vinte e cinco para seis por cento. E ninguém viu acontecer.
4. Na Pilar, a hora real aparece contra o orçado enquanto o projeto anda.
5. Descobrir no fim não adianta. Tem que ser durante.

## Como gravar e finalizar

1. Grave na vertical (câmera traseira, luz de janela, microfone de lapela). Teleprompter: `docs/marketing/gravacao/teleprompter.html`.
2. Salve como `docs/marketing/video-v2/footage/fala-05-margem-no-fim.mp4`.
3. Rode `./make.sh fala-05-margem-no-fim dark` em `docs/marketing/video-v2/`. A legenda palavra a palavra, as telas e a trilha entram sozinhas.
4. Rode `python3 docs/marketing/conteudo/organizar.py` para trazer o vídeo para esta pasta.
