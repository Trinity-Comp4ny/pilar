# Financeiro: legenda do donut dentro do card

Visão Geral > Detalhamento de Receitas/Despesas. Antes, a legenda do Recharts tinha altura
fixa de 36px e vazava do card com muitas categorias. Depois, a legenda é uma lista que
cresce junto com o card. Dados de seed, 1200px de largura, mesmo componente real
(`DonutChart`) nas duas versões (antes = `origin/staging`).
