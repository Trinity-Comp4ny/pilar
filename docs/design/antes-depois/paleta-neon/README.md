# Paleta neon: antes e depois

`componentes.jpg` renderiza botão, aba, badges de status, fills sólidos, barra de gráfico e alertas com o
`tokens.css` de `origin/staging` (ANTES) e o da branch (DEPOIS), lado a lado. Só tokens e CSS, sem dado.
Sem Docker local, as telas reais ficam para o teste visual do CI (label `atualizar-visual`).
