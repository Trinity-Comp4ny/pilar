Quando se fala em software para escritório de arquitetura, quase sempre se pensa em ferramenta de projeto: CAD, BIM, modelagem e renderização. Elas produzem o desenho e o modelo. Mas não respondem quanto o escritório vendeu, qual disciplina está atrasada, quem é o responsável pela próxima entrega ou qual parcela o cliente ainda não pagou. Isso é trabalho de um sistema de gestão. Um não substitui o outro: o escritório precisa dos dois, cada um no seu papel.

Abaixo, o que cada tipo de software resolve, onde eles se encontram e como perceber que o escritório tem ferramenta de projeto de sobra e gestão de menos.

## Qual a diferença entre software de arquitetura e software de gestão?

O software de arquitetura cuida do **objeto**: o edifício, a planta, o modelo, a prancha. O software de gestão cuida do **negócio**: o cliente, a proposta, o contrato, o prazo, a equipe e o dinheiro.

| Pergunta do dia a dia                                             | Quem responde                            |
| ----------------------------------------------------------------- | ---------------------------------------- |
| Como fica a fachada com essa esquadria?                           | Ferramenta de projeto (CAD, BIM, render) |
| A viga interfere no forro do banheiro?                            | Ferramenta de projeto (modelo federado)  |
| Quantos m² de revestimento a obra vai precisar?                   | Ferramenta de projeto (quantitativos)    |
| Quantas propostas fechamos este mês e por que perdemos as outras? | Sistema de gestão                        |
| O executivo da residência X está no prazo?                        | Sistema de gestão                        |
| Quem pega a disciplina quando o anteprojeto fechar?               | Sistema de gestão                        |
| Quanto o cliente já pagou e quanto falta?                         | Sistema de gestão                        |
| O cliente pode ver o andamento sem me ligar?                      | Sistema de gestão (portal do cliente)    |

O BIM, inclusive, organiza muita informação do projeto: elementos, revisões, quantitativos. Mas é informação sobre o edifício. Ele não sabe que a proposta foi aprovada com três parcelas, que a segunda venceu ontem ou que o cliente pediu uma mudança que não estava no escopo.

## Por que só a ferramenta de projeto não organiza o escritório

Escritório que investe pesado em ferramenta de projeto e nada em gestão costuma ter um sintoma conhecido: o desenho é ótimo e o escritório anda no improviso. Algumas formas de perceber:

- A proposta é montada no editor de texto a partir da última parecida, e o escopo vendido mora num anexo de e-mail.
- O prazo de cada projeto está na cabeça do sócio ou numa planilha que só ele atualiza.
- A parcela atrasada só aparece quando alguém abre o extrato no fim do mês.
- A pergunta "em que pé está?" chega por mensagem, e a resposta toma meia hora de quem estava desenhando.
- Ninguém sabe dizer quais tipos de projeto deram dinheiro no último ano.

Nenhum desses problemas se resolve com um modelo melhor. São problemas de informação que não passa do comercial para a produção, nem da produção para o financeiro. Para o caminho de organização completo, veja [como organizar um escritório de arquitetura](/blog/como-organizar-escritorio-arquitetura).

## Por que só a gestão também não resolve

O contrário também acontece, com menos frequência. Sistema de gestão não desenha, não compatibiliza e não gera prancha. Ele não deveria tentar. O que ele faz é dizer **qual** prancha precisa sair, **até quando**, **por quem** e **o que acontece** quando ela sai: a próxima disciplina começa, a parcela do marco é faturada, o cliente vê a entrega.

Ferramenta que promete fazer as duas coisas costuma fazer uma bem e a outra pela metade. Para o escritório, o arranjo que funciona é a ferramenta de projeto que a equipe já domina somada a um sistema de gestão feito para escritório de projeto.

## Onde a ferramenta de projeto e a gestão se encontram

As duas camadas se tocam em poucos pontos, e é neles que vale ter disciplina de processo:

1. **Etapa e disciplina.** O que no arquivo é "anteprojeto revisão 2" na gestão é uma disciplina com status, responsável e prazo.
2. **Revisão.** Cada rodada de revisão pedida pelo cliente é trabalho na ferramenta de projeto e, se passar do combinado, um [aditivo de projeto](/blog/aditivo-de-projeto) na gestão.
3. **Entrega.** Quando a prancha sai, o status muda, o próximo responsável é avisado e, se a entrega for marco de pagamento, a parcela entra na conta.
4. **Compatibilização.** O conflito é encontrado no modelo; o prazo para resolver e quem resolve ficam na gestão. Veja [compatibilização de projetos](/blog/compatibilizacao-de-projetos).

Uma regra prática: o arquivo guarda o desenho, o sistema guarda a decisão. Quem mudou a data, por quê, quem aprovou o escopo, quanto foi cobrado.

## Software para escritório de arquitetura: o que procurar na gestão

Se a ferramenta de projeto já está resolvida, a lista para escolher a gestão é curta:

- **Entende projeto como conjunto de disciplinas e etapas**, não como lista de tarefas genérica.
- **Proposta vira projeto sem redigitar**, com as disciplinas e as parcelas que foram vendidas.
- **Prazo com histórico:** mudança de data registrada com motivo.
- **Financeiro ligado ao contrato:** quanto foi contratado, recebido e está atrasado em cada projeto.
- **Visão para o cliente** sem montar relatório à mão.
- **Preço por escritório**, para não pensar duas vezes antes de dar acesso a um estagiário.

O passo a passo de avaliação, com perguntas para a demonstração, está em [sistema de gestão para escritório de arquitetura](/blog/sistema-gestao-escritorio-arquitetura). Se hoje a gestão é uma planilha, vale ver também a comparação entre [planilha e sistema](/vs/planilha).

## Perguntas frequentes

### BIM substitui um sistema de gestão no escritório de arquitetura?

Não. O BIM organiza a informação do edifício: elementos, revisões do modelo, quantitativos. A gestão organiza o negócio: proposta, contrato, prazo por disciplina, equipe e recebimento. Um escritório maduro em BIM continua precisando saber quanto vendeu e o que está atrasado.

### Escritório pequeno precisa de software de gestão?

Precisa quando a cabeça do sócio deixa de dar conta: vários projetos ao mesmo tempo, mais de uma pessoa produzindo, parcelas espalhadas. Antes disso, uma planilha bem cuidada resolve. O sinal de troca é perder prazo ou dinheiro por falta de informação, não o tamanho da equipe.

### Dá para integrar a ferramenta de projeto com a gestão?

O que importa integrar é o processo, não o arquivo. Definir que toda entrega muda o status da disciplina, que toda revisão fora do escopo vira aditivo e que toda mudança de data tem motivo já conecta as duas camadas, mesmo sem nenhuma integração técnica entre os softwares.

### Software de gestão de construtora serve para escritório de arquitetura?

Em geral, não. Sistema de construtora é pensado para orçamento de obra, suprimentos e medição de empreiteiro. Escritório de arquitetura vende projeto por etapa e disciplina, e precisa de proposta, prazo por disciplina e recebimento por marco.
